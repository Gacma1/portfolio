# Abdukadir Omar Hassan — Portfolio

A responsive personal portfolio built with semantic HTML5, CSS3, and vanilla JavaScript. No frameworks or build tools are required.

## Run locally

1. The current CV is `assets/cv/CV_Abdukadir_Omar_Hassan_Original_Design.pdf`.
2. Optionally replace the profile placeholder in the hero with your own image.
3. Open `index.html` in a browser.

For the most reliable PDF preview behavior, serve the folder with a simple local server such as VS Code Live Server. The page itself also works when opened directly as a local HTML file.

## Customize

- Edit content in `index.html`.
- Update colors, spacing, and responsive behavior in `css/style.css`.
- Update interactions and form behavior in `js/script.js`.
- Replace placeholder LinkedIn, email, phone, certificate, GitHub, and live-demo links with your real details.
- Project cards are filtered with the `data-category` attribute: `web`, `ml`, or `mobile`.
- Contact form submissions are sent to `cabdiqaadirgacmadheere93@gmail.com` through FormSubmit. On the first submission, confirm the activation email FormSubmit sends to that Gmail inbox; submissions will not arrive until the address is activated. FormSubmit's reCAPTCHA remains enabled, and it may take the visitor to FormSubmit's confirmation page after submission.
